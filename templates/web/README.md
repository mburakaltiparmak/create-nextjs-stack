# Website

Generated by [create-nextjs-stack](https://github.com/mburakaltiparmak/create-nextjs-stack). Content is managed in the admin panel.

```bash
npm install
npm run dev            # http://localhost:3000
```

| Where | What |
| --- | --- |
| `src/lib/content/service.ts` | Reads posts and pages from the data source (cached, tag-revalidated; drafts in preview). |
| `src/app/` | Home, `/blog`, `/blog/[slug]`, `/[slug]` (pages), `/contact` |
| `src/app/api/contact` | Contact form → lead in the data source + email via Resend |
| `src/app/api/preview` | Draft preview with the admin's signed token (`PREVIEW_SECRET`) |
| `src/app/api/revalidate` | `POST { secret, tag?, path? }` with `REVALIDATION_SECRET` — the admin calls it after publishing |

Without credentials the site still builds and renders empty lists, so you can work on the design first.

```bash
npm run lint && npm run typecheck && npm test && npm run build
```
