# Admin

Content panel generated by [create-nextjs-stack](https://github.com/mburakaltiparmak/create-nextjs-stack).

```bash
npm install
npm run dev            # http://localhost:3001   (the website runs on 3000)
```

## How it works

| Where | What |
| --- | --- |
| `src/lib/models/site.ts` | **The content model.** Content types and fields; forms, Zod validation, lists and storage mapping are generated from it. |
| `src/lib/content-store.ts` | Data-source adapter (list, get, create, update, publish, unpublish, delete). |
| `src/lib/backend.ts` | Which data source and image mode the panel uses. |
| `src/app/actions.ts` | All writes are server actions; each one re-checks the session (`requirePrincipal`). |
| `src/lib/authorization.ts` | Sign-in specific: who the current user is and what they may do (`can`). |
| `src/lib/i18n/` | Every visible text (`en.ts`, `tr.ts`); `index.ts` picks the language. |
| `src/components/` | shadcn/ui primitives (`ui/`), the shell, `ContentForm`, `ActionForm`. |

### Content

- **Saving creates a draft.** Publish from the list or the edit page; "Preview" opens the draft on the website (same `PREVIEW_SECRET` in both apps).
- **Field kinds:** text, textarea, markdown, slug, url, link, number, date, select, boolean, image, reference (link to another type), list.
- **Several languages:** add locales to the model and mark fields `localized: true`. Each language is its own column/field (`title`, `title_tr` …); only the primary language is required.
- **New content type:** add the table / migration, then the type in `src/lib/models/site.ts` — it shows up in the sidebar.

### Leads

The website's contact form stores every enquiry; the **Leads** screen tracks status and internal notes. Set a retention period there; a daily Vercel cron (`vercel.json`, `CRON_SECRET`) deletes older enquiries.
